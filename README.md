# Wall Street English × BDGOAL — Interactive Web Pitch

A 19-screen, browser-based strategic growth presentation. **No build step or framework required.**

## Deploy to GitHub Pages

1. Create a public or private repository (with GitHub Pages available on your plan).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Go to **Settings → Pages** → **Build and deployment: Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.
5. Open the published URL, usually `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.

You can also drag `index.html` into your browser locally. The deck itself requires no JavaScript libraries. Google Fonts are optional; it falls back to system fonts if offline.

## Navigation and motion

- Right/left arrow keys, Page Down/Up, or scroll wheel: next/previous slide.
- Spacebar: reveal the next animated element, then advance.
- 1/2/3/4: jump to chapters.
- F: toggle fullscreen.
- Click chapters and next/previous buttons.
- On mobile, swipe left/right.
- Interactive content: slide 5 positioning cards, slide 6 academic proof, slide 8 capabilities, slide 17 learner journey.
- Animated metrics: slide 11.
- To reduce motion, use the operating system's **Reduce Motion** accessibility setting.

## Editing

- Slide copy and structure: `index.html`
- Colors, design and animation timing: `styles.css`
- Interaction and transitions: `script.js`

## Important pre-publication notes

- Pricerite performance figures are derived from the shared 10-post Threads tracking sheet; they are not unique reach, sales or lead results.
- Academic proof and DSE/EMI mapping require confirmation with WSE's academic team. Do not claim guaranteed outcomes.
- Premium positioning is a proposed strategic territory, not a verified price comparison.
- Verify permission to publish all named client case studies before deploying the site publicly. GitHub Pages is normally publicly accessible. For a confidential GM pitch, use a secured hosting solution instead.
- SleekFlow/CRM/WhatsApp integrations are illustrative and depend on actual platform availability, technical feasibility and privacy requirements.
