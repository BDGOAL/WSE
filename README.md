# BDGOAL Interactive Motion Lab

Eight working, mobile-first motion concepts for the BDGOAL agency presentation. This is a standalone demonstration, not the 19-slide client pitch.

## Open locally
Double-click `index.html` in a modern browser, or use a local static file server.

## GitHub Pages
Upload `index.html` and the `assets` folder to your repository root, then configure GitHub Settings → Pages → Deploy from a branch → main → /(root).

## Samples
1. Orbit System — orbiting capabilities with tappable nodes.
2. Constellation Network — animated connecting lines with focused node relationships.
3. Capability Wheel — six interactive capability segments.
4. Expanding Core — sequential expansion/collapse animation.
5. Modular Blocks — build a custom capability mix.
6. Human-Centred Hub — photo-led clickable capabilities.
7. Integration Engine — inputs become sample business outcomes.
8. Shape-Shifting Identity — interactive geometric identity transitions.

Touch and mouse interactions work without third-party dependencies. Supports `prefers-reduced-motion`. The photo assets are illustrative AI-generated content, not BDGOAL/WSE campaign photography.

Important brand rule: always use BDGOAL as a single word, with GOAL optionally highlighted but not separated spatially.
