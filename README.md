## Deploy
Upload contents of this ZIP to the root of your GitHub Pages repository; ensure `index.html`, `styles.css`, `script.js`, and `assets/` are present. Go to Settings → Pages → Deploy from a branch → main → /(root).

## Navigation
Use visible left/right arrows or keyboard arrow keys, and tap on interaction cards. Scrolling within long mobile slides stays within that slide and will not advance.
